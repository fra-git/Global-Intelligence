# Global Intelligence

Executive OSINT briefing engine: four daily Telegram dispatches (AM/PM, Part 1/2) covering EU-centred macro, geopolitics, deep tech, space and energy.

- `prompts/system_prompt.md` — system prompt (role, sourcing rules, sentiment engine, templates, 3,800-char Telegram limit).

Each run supplies `{{DISPATCH_TYPE}}` (`AM_PART_1`, `AM_PART_2`, `PM_PART_1`, `PM_PART_2`), `{{DATETIME}}`, and the source material to synthesize.
